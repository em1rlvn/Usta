# Usta Turkish Restaurant

Многоязычный сайт ресторана Usta Turkish Restaurant в Бишкеке. Интерфейс доступен на русском, кыргызском и турецком языках; выбранный язык сохраняется в браузере.

## Локальный запуск

```bash
npm install
npm run dev
```

Сайт откроется по адресу [http://localhost:3000](http://localhost:3000).

## Production-проверка

```bash
npm run build
npm run start
```

## Vercel

Проект использует стандартный Next.js и не требует специальной конфигурации. В Vercel достаточно импортировать GitHub-репозиторий, оставить Framework Preset `Next.js` и выполнить Deploy.
